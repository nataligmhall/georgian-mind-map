# Georgian word map

An interactive map of Georgian words, grouped by theme. Click a dot to open that theme. Search in Georgian or English. A core list of 500 words tracks what you already know.

https://nataligmhall.github.io/georgian-mind-map/

The dictionary data comes from [Wiktionary](https://kaikki.org) extracts in this repo (`kaikki.org-dictionary-Georgian-*.jsonl`). `build.py` turns those files into the pages under `themes/`.

Related projects: [Kartuli Quest](https://kartuli-quest.vercel.app), a 1,000-word quiz, and [Milo](https://nataligmhall.github.io/Milo-Georgian/), the lesson set.
